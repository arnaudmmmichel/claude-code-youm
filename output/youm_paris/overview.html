Modèles & coûts par type de contenu

Quel modèle IA génère chaque type de contenu Youm, et à quel coût approximatif par génération. Sert à décider quel format utiliser quand le budget API compte (ex : image AI-model vs carte Cloudinary texte, qui ne coûte presque rien).

Chiffres approximatifs, pas une facture. Les coûts ci-dessous sont des estimations basées sur les tarifs publics par token/génération au moment de la construction de ces skills (2026-07-21/22) et sur les tailles de prompt réellement observées pendant les tests de ce repo — pas un relevé de consommation réelle. Les prix des fournisseurs changent sans préavis. Pour le coût réel exact, toujours vérifier le tableau de bord de facturation du fournisseur (liens en bas de page).

Les cartes Cloudinary (Instagram et Pinterest) coûtent quasiment rien — le texte via Claude est bon marché, le rendu Cloudinary est inclus dans le forfait existant. Les images AI-model coûtent nettement plus cher (résolution 2K, modèle image dédié), et la vidéo est de loin la plus chère du pipeline (génération ~10x plus longue). Pour un volume de publication élevé à coût maîtrisé, privilégier les cartes texte ; réserver l'image/vidéo AI-model aux pièces phares.
